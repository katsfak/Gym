# 🏋️ Gym

A Unity-based gym simulation/management game built with C# and custom shaders.

## 📋 Overview

Gym is a Unity project that simulates a gym environment.  This project demonstrates game development skills including 3D environment design, gameplay mechanics, and custom shader programming.

## 🎮 Features

- **Immersive 3D Environment**: Fully realized gym space with interactive elements
- **Custom Shaders**: Enhanced visual effects using ShaderLab and HLSL
- **Dynamic Gameplay**: Interactive gym simulation mechanics
- **Optimized Performance**: Efficient C# scripting for smooth gameplay

## 🛠️ Technology Stack

- **Engine**: Unity
- **Programming Language**: C# (85%)
- **Graphics Programming**: ShaderLab (12.7%) & HLSL (2.3%)
- **Version Control**: Git

## 🚀 Getting Started

### Prerequisites

- Unity Editor (2020. 3 LTS or later recommended)
- Visual Studio 2019/2022 or VS Code with C# extension
- Git

### Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/katsfak/Gym.git
   cd Gym
   ```

2. **Open in Unity**
   - Launch Unity Hub
   - Click "Open" or "Add"
   - Navigate to the cloned repository folder
   - Select the project

3. **Wait for Unity to import assets**
   - Unity will automatically import all assets and compile scripts
   - This may take a few minutes on first load

4. **Open the main scene**
   - Navigate to `Assets/Scenes/` in the Project window
   - Double-click the main scene to open it

5. **Press Play to run the game**

## 🎯 Usage

1. Open the project in Unity Editor
2. Navigate to the Scenes folder in the Assets directory
3. Open the main game scene
4. Click the Play button to test the game
5. Use the Game view to interact with the gym environment
